# Global Playground

I help run Global Playground, a curated membership community for founders and entrepreneurs, based in Perth.

We build in the open where we can. The first thing to share is the Agent Board: a plain-file task board where your AI agents split the work and the founder only steps in to answer a question or sign something off. It is free to copy and adapt.

## What you will find here

- **Agent Board template**: a locking script, a working agreement for your agents and a sample task list. Built for founders who run lean and want their AI tools to stop tripping over each other.
- More working systems for founders, shared as they are ready.

## What Global Playground does

Four pillars shape the community: Gather, Spotlight, Banter and Evolve. Members meet, get seen, talk straight and keep growing, and they get the full playbook library as part of joining.
